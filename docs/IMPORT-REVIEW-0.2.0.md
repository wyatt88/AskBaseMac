# 0.2.0 导入更新独立审查

交付日期：2026-10-09，Asia/Shanghai。主代理实现并整合导入更新；另一代理独立编写 `ImportRegressionTests.swift`，使用单独的构建目录和隔离资料库进行检查。审阅者没有修改实现文件。

首轮 13 个回归测试中 5 个通过、8 个失败，暴露 1 项 P1 和 7 项 P2。修复后审阅者重跑相同的 13 个测试，全部通过、零失败；五个相关实现／测试文件在这次重跑前后的 SHA-256 一致。主代理完整运行的 91 个 Swift 测试也全部通过。

| 编号 | 级别 | 首轮问题 | 修复及关闭依据 |
| --- | --- | --- | --- |
| I01 | P1 | 斜线与组合标记组成一个 Swift Character，绕过原文路径分段检查，可沿中间符号链接删除隔离测试库外的文件 | 按 UTF-8 字节分段并验证单组件文件名；相同测试拒绝异常路径，库外 sentinel 保留 |
| I02 | P2 | 合法的组合字符扩展名被误拒绝 | 用字节检查 UUID 后的扩展名分隔符；导入、重索引和删除均通过 |
| I03 | P2 | `notes.中文` 从 URL 删除扩展名后得到空标题 | 从原始文件名计算标题并提供非空回退；导入、删除通过，源文件保留 |
| I04 | P2 | metadata 写入失败后留下无记录的原文副本 | 记录提交前失败清理副本；强制插入失败后重开库仍无残留文件或记录 |

另五项覆盖组合字符分块与重叠还原、读取边界两侧的快照／哈希／原文一致性、复制已有进度后的取消清理、取消后可重试的完整无扩展名副本、取消重索引保留旧索引。

审阅没有读取用户真实资料、调用付费服务或操作生产模型。I01 的删除触发仅使用独立临时目录中的 sentinel，不是用户文件受损记录。I05 覆盖已替换的目录及文件符号链接，不据此宣称抵御全部并发文件系统替换竞态。

证据：源码方法 E2／支持，回归检查为本地工程实验；不是论文复现、业务 E4 或全面安全认证。测试辅助代码在当前 Swift 5 语言模式下有一条更严格 Swift 6 模式的并发警告，现有构建和检查成功；它不属于发布应用代码。
