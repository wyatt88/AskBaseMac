# 0.3.0 多模态审阅记录

日期：2026-10-09。负责人：主代理／推理与 Agent 工程整合。协作：媒体预处理、模型服务、原生界面三个独立写入范围；另设只读核心审阅者。

## 独立审阅范围

审阅者检查媒体元数据、导入、KnowledgeEngine、LibraryStore、模型客户端和检索，以及新增客户端／核心用例。首轮运行 45 项离线检查，其中包括自行构造的 7 个生命周期用例；没有确认仍需阻断交付的 P1/P2。该审阅不覆盖整个服务或原生 UI，也不代表独立检索质量评估。

主代理复核代码和日志后发现：导入期间删除长媒体虽不会复活资料，但首段返回后仍可能继续编码其余片段。因此在每批文本、每段媒体准备前，以及准备后发 HTTP 前再次检查当前资料存在状态。独立审阅者用暂停首段响应的替身复跑 **7/7**，确认删除后总编码次数只有 **1**。

测试已加入 `Tests/AskBaseCoreTests/IndependentMediaLifecycleTests.swift`，并包含在完整 131 项通过结果中：

- 取消导入后保留失败记录及副本，可重试成功。
- 取消重建保留旧索引和同时修改的标题／标签。
- 导入或重建中途删除不复活记录、不残留受管副本；导入删除停止后续编码。
- 检索响应迟到时，已删除来源或知识库不重新出现。
- 跨知识库相同文件互不干扰。
- 精确媒体位置／OCR 来源参与引用校验；篡改帧信息拒绝入库，重建变化撤销旧引用。

## 主代理整合审阅与修复

1. **文本兼容**：原 `encoder.py` 字节不变；服务启用媒体前核对 6 组文本向量。媒体签名独立于旧文本签名，应用同时核对两者。
2. **真实内容**：模型收到图片字节、PCM 音频和原生 video processor 输入；占位文字不进入 embedding、关键词正文或文字问答。OCR 来源每次重新计算。
3. **完整时序**：检查从零到结束的连续范围。20.25 秒合成音频为三段；10.25 秒有声和无声视频为两段。10.005 秒和 20.001 秒边界另有离线测试，整个不足 20 毫秒的音频明确报错。
4. **本机输入**：导入以稳定普通文件副本为准；重建核对原文件 SHA256。AVFoundation 解码与预览均禁止外部媒体引用；服务不接受文件路径或 URL 作为媒体载荷。
5. **资源与取消**：逐段解码和编码；APFS clone／经 inode 核查的硬链接避免为每段重复整文件复制。服务单 worker 串行，HTTP 取消不提前释放实际模型占用。
6. **问答证据**：纯媒体源在 top-K 前排除；只有实际文字／OCR 可发送本地回答模型。新增媒体不会迫使旧文字资料重建。
7. **原生 UI**：核对请求代次、迟到结果、来源关闭、原件验证、播放器观察者清理、禁止自动播放。实际窗口检查覆盖图片和音频；视频仍保留未做窗口播放验收的边界。

开发中修正了 CMTimeRange 参数标签、异步 XCTest 写法，以及工作文件编辑过程中的编译问题。最终完整构建和 **131/131** 核心测试通过；真实模型媒体 **27/27**、原文问答 **15/15**、文档格式 **18/18**、原生窗口／状态 **75/75** 通过。没有将前期编译失败描述成通过。

## 证据边界

模型服务自身有 45 项离线检查和 10 次合成媒体真实调用；本机完整服务升级另由主代理执行并核对。原生 UI 工作项先做 33 项离线状态检查，再由主代理统一运行真实窗口／模型流程，避免重复消耗模型预算。

代理意见不是独立统计样本；离线替身、原生窗口截图、真实模型工程集成、人耳听音／连续观看和真实语料检索质量分别判断。后两项本轮未完成。详细产物和运行配置见 [0.3.0 验收](MULTIMODAL-UPDATE-0.3.0.md)。
