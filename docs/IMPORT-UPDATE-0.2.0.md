# 0.2.0 导入更新与验收

交付日期：2026-10-09，Asia/Shanghai。原始运行时间戳保留在检查产物中。

用户要求取消导入文件的大小、数量和格式限制。本版移除固定配额，改为按实际内容提取文字，保留完整索引提交、可取消和逐文件失败反馈。

## 行为变化

| 原行为 | 0.2.0 |
| --- | --- |
| 单文件最多 32 MiB、提取文本最多 200 万单元 | 不设固定字节或文本长度配额 |
| PDF 最多 2,000 页 | 遍历全部页面，保留原页码 |
| 最多 1,000 个文件、10,000 个目录条目、16 层目录 | 不设这些配额；显式选择后遍历 |
| 扩展名白名单 | 根据内容识别，文本可无扩展名或使用自定义扩展名 |
| 主要支持文本和 PDF | 增加 RTF、DOCX、XLSX、PPTX、ODT、EPUB、UTF-32；本地 HTML 提取正文 |

文件夹导入跳过隐藏后代、应用包和符号链接；隐藏普通文件可直接选择。文件原文、SHA-256 和解析内容来自同一份磁盘快照，复制与哈希使用 1 MiB 缓冲。分块不再为全文构建 Character 数组。

## 提取与容量边界

- 不支持图片／扫描 PDF 的 OCR、音视频转写、旧版二进制 Office、XLSB、iWork 或加密文档。无可用文字时明确报告原因。
- DOCX 覆盖主正文；页眉、页脚、脚注尚未提取。`altChunk` 合并正文需先用 Word 打开并另存。PPTX 不提取演讲备注。
- XLSX 读取存储值或公式文字，不重算公式、不还原日期显示样式；图片、图表及排版不构成已验证提取能力。
- 模型与索引接口保持兼容，无需迁移旧库；需要补入新支持的内容时可重新导入或重建索引。
- 文本、分块和向量仍占用内存，快照和原文副本占用磁盘；取消固定配额不代表资源无限，也不是完整的磁盘流式索引实现。
- 当前为 Apple Silicon 本地临时签名包；没有 Apple 公证、macOS 14 实机、干净 Mac 安装、真实私人语料质量或长期大规模负载验收。

这些结果是原创工程实现的本地运行检查，不标作论文 E3 复现或真实业务 E4 验证。源码和方法审查为 E2；对于本次覆盖的工程断言，结论为支持。
